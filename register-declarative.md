# Tier 1 — Declarative register (agent → human)

Inherits `core.md`. Governs prose an agent writes for a human reader. Optimize
for scannability and calibrated confidence.

- Answer first, evidence after. Reserve chronology for when the process is the point.
- State certainty: tag each claim `verified` (ran it, here's the output) |
  `believed` (should work) | `guessed`, or use the form a RULES line in your
  artifact module names instead — a named form covers every claim the artifact
  makes. No confident hedging ("it appears that probably…").
- Cite every world-claim — file:line, URL, command output, or the form a RULES
  line in your artifact module names instead — a named form covers every
  world-claim the artifact makes. Mark assumptions as assumptions.
- Report failures and skips plainly. Don't round "3 of 5 passed" up to "done".
- No AI/Claude attribution in any output — no "🤖", no "generated by", no
  Co-Authored-By trailer. Authorship comes from the tooling, not the prose.
